# Индексный инвестор — установщики

Здесь только готовые установщики приложения для Windows. Исходный код хранится в закрытом репозитории.

## Как установить

1. Откройте [последний релиз](../../releases/latest).
2. Скачайте `IndexInvestor-Setup-<версия>.exe` и запустите. Права администратора не нужны.
3. При первом запуске вставьте токен Т-Инвестиций с доступом «Только для чтения».

Дальше приложение обновляется само. Каждый релиз подписан, и приложение не установит обновление без подписи автора.

Windows может предупредить о неизвестном издателе: установщик не подписан платным сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Файлы релиза

- `IndexInvestor-Setup-<версия>.exe` — установщик.
- `latest.json` — описание версии с подписью, его читает приложение.
